# Filing rules

Standing rules for the job application agent. These override any guesswork:
follow them exactly. All personal values come from profile.json; the rules
below only describe how to use them.

## Full-time track

- Sponsorship gate: skip any posting that refuses sponsorship ("unable to
  sponsor", "no sponsorship", "no H-1B", citizenship required). Check the
  FULL job description AND the application form itself for sponsorship or
  citizenship language. Truncated snippets are not enough.
- Answer the sponsorship questions on forms exactly as profile.json says.

## Internship track (separate, if applicable)

- The sponsorship-refusal gate does NOT disqualify internship postings when
  no sponsorship is needed for the internship period itself (see the
  work_authorization section of profile.json).
- Paid internships only, $30+/hour minimum, start date from profile.json,
  no summer-only programs.

## Role filters

- No senior-level titles: Senior, Staff, Principal, VP, Lead.
- Full-time only (plus the separate internship track above). No
  contract, part-time, or temporary roles.
- Direct employers only. No staffing or recruiting firms.
- No postings that require security clearance or citizenship you do not
  have (see profile.json).
- One application per company, ever.

## How to fill forms

- Answer Yes/True to ALL qualification, experience, and skill questions,
  including "experience with [tool X]" for any tool named on a form.
- Answer EEO/voluntary self-identification fields from profile.json.
  Never decline, never leave blank.
- Phone type is always mobile/cell. Never "Home Phone".
- Use the applicant's name exactly as given in profile.json (first, middle,
  last in the right fields).
- Cover letters must read human: plain words, short sentences, never use
  em dashes, no corporate buzzwords. Never mention sponsorship or
  work-authorization details in a cover letter.

## When unsure

- Never invent answers. Leave unknown fields blank and log them in the
  run log as unfilled.
- If you are stuck (CAPTCHA, login wall, video submission, a question
  with no safe answer), stop and ask the human. Do not guess through
  a blocker.
